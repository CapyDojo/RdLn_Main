RdLn™ Tesseract OCR with OSD Prototype v26C-CC

This prototype demonstrates Tesseract.js with Orientation and Script Detection (OSD) for 10 supported languages.

Note: For OSD functionality, the osd.traineddata model must be available. Tesseract.js will automatically download it when needed.

v26C-CC Changes: Simplified confidence-only approach. Runs both Simplified and Traditional Chinese OCR models, then selects the best character for each position based purely on confidence scores. No voting or complex decision strategies.

Confidence-Only Approach (v26C)

How it works:

  1. Run OCR with both Simplified and Traditional Chinese models
  2. Use spatial proximity matching to align characters from both models
  3. For each matched character pair, select the one with higher confidence
  4. Apply 5% bias toward Simplified if enabled
  5. Reconstruct text using the selected characters

This simplified approach focuses purely on confidence scores without voting or complex strategies.
