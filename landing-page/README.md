# RdLn Landing Page

This is the landing page for the RdLn application.

## Setup

1.  Navigate to this directory: `cd landing-page`
2.  Install dependencies: `npm install` (if not already done)
3.  Start the development server: `npm run dev`

## Deployment

To build for production:
`npm run build`

## Installer File

The "Download for Windows" button links to `/RdLn-Setup.exe`.
Please place the actual installer file in the `public` directory of this project so it can be downloaded.
