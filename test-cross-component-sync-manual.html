🧪 Cross-Component Synchronization Test Suite

Manual testing interface for RdLn Memory synchronization across components

📋 Test Instructions

This page provides manual tests to verify that RdLn Memory synchronization works correctly across all components. Follow the test steps below and verify the expected behavior.

Prerequisites: Make sure the RdLn application is running and the RdLnMemoryProvider is properly integrated.

Test 1: Save in Side Panel → Appears in Dropdown (Requirement 1.1)
Step 1: Open the RdLn Memory side panel by clicking the memory tab on the right edge
Step 2: Add some test content to both Original and Revised text areas:
Original: "This is test content for synchronization verification"
Revised: "This is modified content for synchronization verification"
Step 3: Click "Save Current Session" in the side panel
Step 4: Close the side panel and open the RdLn Memory dropdown (click the memory button in the controls)
Expected Result: The session you just saved should appear immediately in the dropdown without requiring a page reload
⏳ Test not completed yet
Test 2: Delete in Dropdown → Disappears from Side Panel (Requirement 1.2)
Step 1: Ensure you have at least one saved session (from Test 1 or create a new one)
Step 2: Open the RdLn Memory dropdown and locate a saved session
Step 3: Click the delete button (trash icon) next to the session in the dropdown
Step 4: Close the dropdown and open the side panel
Expected Result: The deleted session should no longer appear in the side panel without requiring a page reload
⏳ Test not completed yet
Test 3: Auto-save in ComparisonInterface → Appears in Both Components (Requirement 1.3)
Step 1: Add content to both text areas and run a comparison by clicking "Compare Documents"
Step 2: Wait for the comparison to complete (this should auto-save the session)
Step 3: Open the dropdown and verify the auto-saved session appears
Step 4: Open the side panel and verify the same session appears there
Expected Result: The auto-saved session should appear in both the dropdown and side panel immediately after comparison completes
⏳ Test not completed yet
Test 4: No Page Reload Required (Requirement 1.4)
Step 1: Open browser developer tools and go to the Console tab
Step 2: Perform several session operations (save, delete, load) across different components
Step 3: Monitor the console for any page reload attempts or full page refreshes
Step 4: Verify that all synchronization happens instantly without any loading states or delays
Expected Result: All synchronization should happen immediately without page reloads, and the browser should not show any loading indicators
⏳ Test not completed yet
Test 5: Session Count Consistency
Step 1: Note the session count displayed in both the dropdown and side panel
Step 2: Save a new session from any component
Step 3: Check that both components show the updated session count
Step 4: Delete a session from any component
Step 5: Verify both components show the decremented session count
Expected Result: Session counts should always be consistent across all components
⏳ Test not completed yet
Test 6: Session Data Consistency
Step 1: Save a session with distinctive content that's easy to identify
Step 2: Open both the dropdown and side panel
Step 3: Verify the session appears with the same name, preview text, and metadata in both components
Step 4: Load the session from one component and verify the content is correct
Expected Result: Session data should be identical across all components, including names, previews, timestamps, and content
⏳ Test not completed yet
