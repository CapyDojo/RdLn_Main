DOCX Numbering Resolver — Minimal, Deterministic Prototype

idle

How to use

  1. Choose a .docx file with numbered lists or outline headings.
  2. Click Parse & Resolve.
  3. Right pane prints paragraphs with computed labels (like Word → Notepad).

Assumptions

  • Final-view semantics (treat changes as accepted).
  • Resolves list numbering from numbering.xml + style-linked numbering.
  • No field evaluation (e.g. SEQ) in this minimal build.
