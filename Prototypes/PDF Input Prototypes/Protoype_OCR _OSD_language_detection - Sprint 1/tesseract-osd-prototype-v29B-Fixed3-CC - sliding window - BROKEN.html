RdLn™ Tesseract OCR with OSD Prototype v29B-Fixed3-CC

This prototype demonstrates Tesseract.js with FIXED Option B: Character-level sliding window alignment for Chinese Traditional vs Simplified OCR models.

Key Innovation: Character-level sliding window analysis that works at character level to avoid word boundary issues where Traditional and Simplified models segment text differently (e.g., "文字" vs "文", "，" vs "輸入").

Note: For OSD functionality, the osd.traineddata model must be available. Tesseract.js will automatically download it when needed.

v29B-Fixed3-CC Changes: Fixed critical bugs + simplified drag and drop to working version from v29A-CC (no complex DOM loading).
