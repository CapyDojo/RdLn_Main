DOCX Track Changes Processing Comparison

Comparing different approaches to handling DOCX files with track changes

About This Prototype

This prototype compares three different approaches to processing DOCX files with track changes:

  1. Standard Mammoth.js - Basic text extraction using extractRawText()
  2. Enhanced Mammoth.js - HTML conversion with style mapping to detect track changes
  3. Custom XML Parsing - Direct XML parsing of DOCX structure for full track change preservation

Upload a DOCX file with track changes to see how each method performs.

For detailed information about this prototype, see the Overview Document.

How to Use This Prototype

  • Select a processing method using the buttons above
  • Drag and drop a DOCX file with track changes onto the drop zone, or click "Select DOCX File"
  • View the extracted content and track change information for the selected method
  • Compare results between different methods using the comparison table
  • Note: Legacy DOC files are not supported. Please use DOCX format.
