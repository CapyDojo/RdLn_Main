DOCX Numbering Resolver — Minimal, Deterministic Prototype

idle

How to use

  1. Choose a .docx file with numbered lists or outline headings.
  2. Click Parse & Resolve.
  3. Left pane shows status; right pane prints paragraphs with computed labels.

Assumptions

  • Final view (changes accepted).
  • Resolves list numbering only (no SEQ/LISTNUM fields yet).
  • Style-linked numbering supported via basedOn chain.
