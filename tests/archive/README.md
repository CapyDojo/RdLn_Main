# Archived Tests

This directory contains tests that have been deprecated or are no longer actively used in the test suite.

## Backup

The `backup` subdirectory contains tests that were previously in the `decommissioned` folder. These tests are kept for historical reference but are not actively maintained or run.

## Purpose

Archived tests are kept for the following reasons:
1. Historical reference for how certain features were previously tested
2. Potential future re-use of test patterns or approaches
3. Documentation of deprecated functionality

## Note

These tests are excluded from the regular test runs and should not be modified unless there's a specific need to restore functionality.
