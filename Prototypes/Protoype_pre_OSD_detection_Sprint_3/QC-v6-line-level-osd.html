RdLn™ Line-Level OSD Analysis - QC-v6

This prototype runs OSD at the line level to detect script for each individual line.

It provides the most granular script detection possible for multilingual documents.

Line-Level OSD Approach:

  1. Run initial layout analysis with PSM 4 (single column)
  2. Extract all lines from the document
  3. Run OSD on each individual line to detect script
  4. Process each line with script-specific models
  5. Combine results preserving script diversity
