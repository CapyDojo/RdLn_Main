RdLn™ Granular Layout Analysis - QC-v3

This prototype implements a practical approach for fine-tuning granularity between PSM 3 and PSM 6.

It automatically identifies complex regions that need more granular processing.

Approach:

  1. Run initial PSM 3 analysis to get paragraph-level segmentation
  2. Identify complex paragraphs using character set analysis and confidence metrics
  3. Apply PSM 6 granular processing to complex regions
  4. Combine results for optimal multilingual handling
