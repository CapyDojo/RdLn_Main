RdLn™ Tesseract OCR - Simple Character Confidence Comparison

This is a stripped-down version that compares Simplified vs Traditional Chinese character confidence scores directly.

Ultra-Simple Approach

How it works:

  1. Run OCR with both Simplified and Traditional Chinese models
  2. Extract all characters from both results
  3. For each character position, select the one with higher confidence
  4. That's it - no voting, no complex structures, no spatial matching
