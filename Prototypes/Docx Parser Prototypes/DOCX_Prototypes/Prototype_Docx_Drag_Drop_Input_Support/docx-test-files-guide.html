DOCX Test Files Creation Guide

How to Create Test DOCX Files

Follow these steps to create DOCX files for testing the prototype:

Note: Legacy DOC files are not supported. Please save your documents in DOCX format.
  1. Open Microsoft Word or any word processor that can save files in DOCX format
  2. Create sample content with various formatting elements: 
    Document Title

This is a paragraph with some **bold text** and some *italic text*.

Here's a list:
• First item
• Second item
• Third item

And a numbered list:
1. First numbered item
2. Second numbered item
3. Third numbered item

Table:
| Column 1 | Column 2 |
|----------|----------|
| Cell 1   | Cell 2   |
| Cell 3   | Cell 4   |
  3. Save the document as "test-document.docx" in the Prototypes folder
    Important: When saving, choose "Word Document (*.docx)" format, not "Word 97-2003 Document (*.doc)" format.
  4. Test with various file sizes:
    • Small file: Simple text (1-2 paragraphs)
    • Medium file: Text with formatting, lists, and a table
    • Large file: Multiple pages of content
Tip: You can also download sample DOCX files from various online sources for testing with different content types and formatting.
