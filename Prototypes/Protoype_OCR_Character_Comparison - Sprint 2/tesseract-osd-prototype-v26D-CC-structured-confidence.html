RdLn™ Tesseract OCR with OSD Prototype v26D-CC

This prototype demonstrates Tesseract.js with Orientation and Script Detection (OSD) for 10 supported languages.

Note: For OSD functionality, the osd.traineddata model must be available. Tesseract.js will automatically download it when needed.

v26D-CC Changes: Structured confidence-only approach. Preserves Tesseract's natural paragraph and line structure while substituting individual characters based on confidence scores. No text reconstruction from coordinates - uses existing structure.

Structured Confidence-Only Approach (v26D)

Key Improvement: Preserves original document structure instead of reconstructing from coordinates

How it works:

  1. Run OCR with both Simplified and Traditional Chinese models
  2. Use Tesseract's existing paragraph/line/word structure from Simplified model as base
  3. For each character position, substitute the one with higher confidence
  4. Apply 5% bias toward Simplified if enabled
  5. Preserve original document structure and reading order

This approach maintains natural text flow while optimizing individual character selections.
