Word Compare Bridge

Scope

  • Windows desktop only
  • DOCX to DOCX only
  • Launches local Word compare
  • Result stays in Word

Notes

This mock UI is intentionally separate from the main product. It is for workflow validation only.

Alternative Comparison Path

Launch Microsoft Word as a secondary comparison engine

Why This Exists

Some legal users may trust Word's comparison results for file-based workflows and want it as a fallback or cross-check.

Out Of Scope

No PDF support, no browser support, no result import back into RdLn, and no production error telemetry in this prototype.
