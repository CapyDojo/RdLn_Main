# Unified Test Dashboard

## Overview

The Unified Test Dashboard consolidates all existing test interfaces into a single, well-organized dashboard that provides access to both standard legal document tests and extreme stress tests. This eliminates the need for multiple separate test interfaces and provides a more cohesive testing experience.

## Features

### 1. Tabbed Interface
- **Standard Tests**: Legal document test cases for regular validation
- **Extreme Stress Tests**: Ultra-complex test cases designed to push the algorithm to its limits

### 2. Comprehensive Test Management
- Run all tests or individual tests
- Filter tests by category and difficulty level
- Search tests by name, description, or category
- Load test cases directly into the main comparison interface

### 3. Detailed Results Analysis
- Real-time test execution feedback
- Performance metrics and execution times
- Success/failure indicators
- Detailed statistics and summaries

### 4. Specialized Test Categories
- **Standard Tests**: 
  - Karpathy-inspired address substitution tests
  - Legal document modifications (NDAs, contracts, leases, etc.)
  - Large document performance tests
- **Extreme Tests**:
  - Mega-merger agreements
  - International joint ventures
  - Financial derivatives contracts
  - Pharmaceutical licensing agreements
  - Infrastructure construction contracts
  - Technology transfer agreements
  - Energy project financing
  - Aerospace defense contracts
  - Global supply chain agreements

## Usage

### Accessing the Dashboard
Navigate to `/unified-tests` in the application to access the Unified Test Dashboard.

### Running Tests
1. Select the appropriate tab (Standard Tests or Extreme Stress Tests)
2. Use filters to narrow down the test cases
3. Click "Run All Tests" to execute all visible tests
4. Or click "Test" on individual test cases to run them separately

### Loading Test Cases
Click "Load Test Case" on any test to load the original and revised documents directly into the main comparison interface for analysis.
