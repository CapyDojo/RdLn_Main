RdLn™ Timed Line-Level OSD Analysis - QC-v7

\n

This prototype uses only English worker for first structure analysis, then runs line-level OSD.

\n

It reconstructs the full output and provides detailed timing measurements.

\n \n
\n

Timed Line-Level OSD Approach:

\n
    \n
  1. Run initial layout analysis with English worker only
    2. \n
  2. Extract all lines from the document
    3. \n
  3. Run OSD on each individual line to detect script
    4. \n
  4. Process each line with script-specific models
    5. \n
  5. Reconstruct full output preserving order
    6. \n
  6. Provide detailed timing breakdown
    7. \n
