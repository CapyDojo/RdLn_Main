RdLn™ Tesseract OCR with OSD Prototype v27B-CC

This prototype demonstrates Tesseract.js with Orientation and Script Detection (OSD) for 10 supported languages.

Note: For OSD functionality, the osd.traineddata model must be available. Tesseract.js will automatically download it when needed.

v27B-CC Changes: Implemented sliding window matching algorithm to handle different word detection patterns between Simplified and Traditional models. Uses intelligent word matching within ±3 position window with similarity scoring.

Paragraph Decision Strategy:

Word-Level Vote: Paragraph winner based on which model won more individual words.
Paragraph Confidence: Traditional approach using paragraph-level confidence scores.
Hybrid: Combines word-level votes with confidence weighting.

Sliding Window Matching: This version uses intelligent word matching with a ±3 position window.
  • Exact Match: Same word text gets highest priority
  • High Confidence: Words with >90% confidence get preference
  • Position Proximity: Closer positions get higher scores
  • Unmatched Handling: Words without good matches are handled separately
