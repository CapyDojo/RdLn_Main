🔬 OCR Worker Benchmark v2

Testing Performance: 10-Language Workers (eng, chi_sim, chi_tra, spa, fra, deu, jpn, kor, ara, rus)

ℹ️ Test Description

This benchmark tests the performance difference between:

  • Single Worker Test: Process 2 OCR operations sequentially using 1 prewarmed 10-language worker
  • Dual Worker Test: Process 2 OCR operations using the same OCR service (may or may not use multiple workers internally)

Both tests use the same 10 languages as the main OCR engine: English, Chinese (Simplified), Chinese (Traditional), Spanish, French, German, Japanese, Korean, Arabic, and Russian.
