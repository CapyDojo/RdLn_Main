
# UI/UX Audit and Refinement Plan - 20250714

## 1. Executive Summary

This audit reveals a solid foundational UI with a professional, modern aesthetic. However, several critical issues, primarily related to **accessibility** and **color system integrity**, are undermining the user experience across multiple themes.

The most urgent issues are widespread failures to meet WCAG AA contrast standards for text and buttons, making the application difficult to use for individuals with visual impairments. Additionally, many themes suffer from disconnected and inconsistent color systems, making them difficult to maintain and scale.

This plan outlines a systematic approach to address these issues, starting with immediate accessibility fixes, followed by a theme-by-theme refactoring and a cleanup of global styles.

## 2. Key Issues Across All Themes

-   **Critical Accessibility Failures:** Widespread failure to meet WCAG AA contrast standards, especially in buttons and interactive text.
-   **Inconsistent & Disconnected Color Systems:** `semanticColors` are often disconnected from the core `colors` palettes, frequently due to hardcoded hex values.
-   **Confusing Palette Structures:** Redundant, inconsistent, or confusingly named color palettes add unnecessary complexity.
-   **Flat vs. Glassmorphism Conflict:** Recurring conflict between themes designed to be "flat" and the application's global glassmorphism styles.

## 3. Theme-Specific Audit & Recommendations

### `classic-light`
-   **Issues:** Incorrect "dark theme" description, critical accessibility failures (interactive text, buttons), redundant grey palettes, "flat" vs. glassmorphism conflict.
-   **Recommendations:** Fix description, correct contrast ratios, unify grey palettes, resolve style conflict.

### `classic-dark`
-   **Issues:** Critical button accessibility failure, contaminated color palettes (redline colors mixed with UI colors), inconsistent accent colors, "flat" vs. glassmorphism conflict.
-   **Recommendations:** Fix button contrast, refactor palettes to separate redline colors, clean up accent palette, resolve style conflict.

### `apple-dark` (Excellent)
-   **Issues:** Redundant `secondary` palette, button contrast is borderline (passes AA, but could be improved).
-   **Recommendations:** Remove redundant palette, use a slightly darker purple for buttons, soften harsh white borders.

### `autumn`
-   **Issues:** Critical accessibility failures (interactive text, buttons), "muddy" and low-contrast palette, weak visual hierarchy.
-   **Recommendations:** Fix contrast ratios, increase color vibrancy, strengthen visual hierarchy, re-evaluate glassmorphism use.

### `bamboo`
-   **Issues:** Completely disconnected color system, critical accessibility failures (buttons, interactive text), messy `accent` and `neutral` palettes.
-   **Recommendations:** Rebuild `semanticColors` from palettes, fix contrast ratios, clean up palettes.

### `kyoto`
-   **Issues:** Completely disconnected color system with "brute force" CSS hacks, critical accessibility failures (body text, buttons, interactive text), confusing "inverted" palettes.
-   **Recommendations:** Rebuild `semanticColors` and remove CSS hacks, fix all contrast ratios, simplify and standardize palettes.

### `new-york` (Excellent)
-   **Issues:** Button accessibility failure.
-   **Recommendations:** Fix button contrast, align internal and display names (`new-york` vs. `NYC Dusk`).

### `professional`
-   **Issues:** Disconnected color system with hardcoded values, critical accessibility failures (interactive text, buttons), redundant grey palettes.
-   **Recommendations:** Rebuild `semanticColors` from palettes, fix contrast ratios, unify grey palettes.

## 4. Proposed Action Plan

1.  **Immediate Accessibility Fixes:** Address the most critical accessibility failures across all themes, focusing on button and text contrast.
2.  **Systematic Theme Refactoring:** Go through each theme, one by one, and implement the recommended changes, starting with the most broken themes (`bamboo`, `kyoto`).
3.  **Global Style Cleanup:** Address the "flat" vs. glassmorphism conflict by creating a more robust system for applying theme-specific effects.
