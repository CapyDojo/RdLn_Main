## WAVE-2 details

### LM-WORD-04 — Specific failure messages

File: `src-electron/main.cjs`, the `child.on('close')` mapper after PowerShell Word launch. Optionally tighten renderer fallbacks in `ComparisonInterface.tsx` so they do not overwrite a good main-process message.

Approved buckets. Match case-insensitively against `stderr` / `stdout`. First match wins.

| Condition | `code` | User message |
|-----------|--------|----------------|
| Existing: `80040154`, class not registered, ActiveX, COM class factory | `WORD_NOT_AVAILABLE` | `Microsoft Word does not appear to be installed on this computer.` |
| read-only / access denied / not authorized / 800A1066 | `FILE_READ_ONLY` | `The original file is marked read-only. Remove that restriction or save a copy, then try again.` |
| in use / being used by another / locked / permission denied sharing | `FILE_IN_USE` | `One of the files is open or locked in another program. Close it and try again.` |
| password / protected view / encrypted | `FILE_PROTECTED` | `Word could not open one of the files because it is password-protected or in Protected View.` |
| Existing path validation: missing files | `FILE_NOT_FOUND` | `One or both source files could not be found.` |
| Everything else, non-zero exit | `WORD_COMPARE_FAILED` | `RdLn could not launch Microsoft Word. Please try again.` |

Do not surface raw HRESULTs or PowerShell traces in the UI. Logging them to the existing Electron log is fine.

Keep the existing success string: `Microsoft Word opened with a native comparison.`
