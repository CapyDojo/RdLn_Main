Architecture: Single element with mask. All visual effects (background, border, blur) live on the same element to eliminate seams.

  • Parametric geometry via CSS variables
  • SVG mask path generated at runtime
  • Resize-aware using ResizeObserver
  • Seamless tab-to-panel continuity

✅ Pros

  • Truly seamless surface (one compositing layer)
  • Backdrops, borders, shadows computed once
  • Geometry controlled by CSS vars + TS
  • Responsive and animation-friendly

❌ Cons

  • Mask path math (simple but necessary)
  • Clip/mask transitions need perf consideration
